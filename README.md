# Подбор хороших вин

Приложение для части 4 домашнего задания. Хорошим считается вино с экспертной оценкой не ниже 7. Внутри приложения модель не обучается: загружается готовый пайплайн `StandardScaler + LogisticRegression` из частей 1–3.

Итоговый порог `0.2363586093827868` выбран по валидации: максимальный precision среди порогов с recall не ниже 0.7. На тестовой выборке при нём precision около 0.4213, recall 0.7063 и F1 0.5277. Условие по recall выполнено на этом тесте, но не гарантируется для любых новых данных.

## Содержимое папки

- `app.py` — приложение Streamlit;
- `model.joblib` — весь обученный пайплайн;
- `config.json` — выбранный порог;
- `test.csv` — тестовая выборка с целевым столбцом `target`;
- `requirements.txt` — проверенные версии библиотек;
- `README.md` — инструкция запуска и объяснение кэширования.

Все эти файлы должны находиться вместе в папке `wine_app/`.

## Локальный запуск

Проверено на Python **3.12.14**. Для воспроизводимого запуска используйте Python **3.12** и версии библиотек из `requirements.txt`.

В Windows откройте PowerShell в папке `wine_app` и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

В macOS или Linux:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

После запуска откройте адрес, который появится в терминале, обычно `http://localhost:8501`. Для остановки нажмите `Ctrl+C` в терминале.

Файлы модели, данных и конфигурации ищутся относительно `Path(__file__).parent`, поэтому приложение можно запускать и из другой рабочей папки, указав путь к `app.py`.

## Что есть в приложении

1. **Оценка одного вина.** Вводятся 11 числовых признаков и цвет вина. Минимум, максимум и начальные значения взяты из тестовых данных. Приложение показывает вероятность и решение при текущем пороге.
2. **Модельные метрики.** Ползунок в боковой панели меняет общий порог. Пересчитываются решения, матрица ошибок, precision, recall и F1. На ROC- и PR-кривых отмечается текущий порог.
3. **Пакетное предсказание.** Загружается CSV, показываются вероятности и классы, результат можно скачать. При нехватке столбцов, пропусках или неправильных значениях выводится понятная ошибка. Кнопка «Скачать пример CSV» даёт готовый образец из 10 вин.
4. **Что выучила модель.** Показаны отсортированные коэффициенты после масштабирования признаков и названы признаки с самым большим положительным и отрицательным вкладом.

## Формат CSV

Нужны столбцы в любом порядке:

```text
fixed_acidity,volatile_acidity,citric_acid,residual_sugar,chlorides,free_sulfur_dioxide,total_sulfur_dioxide,density,pH,sulphates,alcohol,is_red
```

Разделитель — запятая, кодировка — UTF-8, десятичный разделитель — точка. `is_red` принимает 0 для белого вина и 1 для красного. Столбец `target` не нужен. Дополнительные столбцы в модель не передаются.

В результате `probability_good` — вероятность хорошего вина, `prediction` — класс 0 или 1 при общем пороге из боковой панели.

## Кэширование — задание 4.5

Для модели используется `st.cache_resource`: модель — общий объект, который загружается один раз и используется при следующих перезапусках приложения. Для таблицы `test.csv`, конфигурации и массива вероятностей используется `st.cache_data`: это данные, и Streamlit возвращает их сохранённые значения, не выполняя повторно чтение или расчёт.

В функции `test_proba(_model, X)` аргумент модели начинается с подчёркивания, поэтому Streamlit не пытается его хешировать. Таблица X участвует в ключе кэша. При движении ползунка X не меняется: функция возвращает уже рассчитанные вероятности теста, а приложение только сравнивает их с новым порогом и пересчитывает метрики. Само изменение порога не вызывает повторный `predict_proba` на тестовой выборке.

Если вызывать `joblib.load` без декоратора, модель будет заново читаться с диска при каждом действии пользователя. Для загрузки модели `st.cache_data` не используется.

## Размещение в Streamlit Community Cloud

1. Загрузите папку `wine_app/` в свой репозиторий GitHub.
2. В Streamlit Community Cloud выберите `Create app` → `Yup, I have an app`.
3. Укажите свой репозиторий и ветку `main`.
4. В поле `Main file path` укажите `wine_app/app.py`.
5. В `Advanced settings` выберите Python **3.12**.
6. Нажмите `Deploy`. После успешного запуска сохраните выданную ссылку на приложение для сдачи.

Файл `requirements.txt` находится рядом с `app.py` и задаёт версии библиотек для облачного запуска. Репозиторий проекта: https://github.com/n1ghtmatr3v/wine-app
